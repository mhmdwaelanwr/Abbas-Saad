# عباس سعد — Media Profile

موقع عربي RTL للإعلامي **عباس سعد**، مقدم برنامج **«الوطن أولاً»** على قناة **الحدث اليوم**.

الموقع مصمم كـ **Media Profile / Press Page** للاستخدام عند مشاركة الملف مع القنوات والصحفيين والجهات الإعلامية، مع الاعتماد على معلومات وروابط منشورة يمكن الرجوع إلى مصدرها.

## المحتوى

- نبذة مهنية مختصرة.
- بيانات أساسية عن البرنامج والقناة.
- أعمال وحلقات مختارة من YouTube.
- قسم مخصص للصحفيين والقنوات يتضمن نبذة قابلة للنسخ وروابط مرجعية.
- خيار طباعة / حفظ الملف كـ PDF من المتصفح.
- بيانات البث المنشورة للقناة: `11823 V / 27500` على نايل سات.
- SEO وOpen Graph وTwitter Card وSchema.org.
- Responsive للموبايل والتابلت والكمبيوتر.
- Accessibility ودعم `prefers-reduced-motion`.

## المواد المرجعية المستخدمة

الموقع يربط بمواد منشورة عبر قناة **AlHadath Alyoum - الحدث اليوم** على YouTube، من بينها:

- «الوطن أولا مع عباس سعد | جولة حول أهم الأحداث والقضايا» — 5 أغسطس 2026.
- «الوطن أولا مع عباس سعد | جولة حول أهم الأحداث» — 22 يوليو 2026.
- «الوطن أولا مع عباس سعد | التحول الاقتصادي في مصر» — 20 مايو 2026.
- «الوطن أولا مع عباس سعد | جولة حول أهم الأحداث» — 28 فبراير 2026.

> لا يتضمن الموقع سيرة ذاتية موسعة أو حسابات شخصية أو بيانات اتصال غير موثقة.
