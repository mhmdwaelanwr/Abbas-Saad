# عباس سعد — إعلامي ومقدم برنامج «الوطن أولاً»

موقع عربي RTL احترافي للإعلامي **عباس سعد**، مقدم برنامج **«الوطن أولاً»** على قناة **الحدث اليوم**.

## ما الذي يقدمه الموقع؟

- واجهة إعلامية حديثة بطابع Editorial / Newsroom.
- Hero رئيسي يعتمد على محتوى عباس سعد المنشور على YouTube.
- قسم تعريفي بالإعلامي وبرنامج «الوطن أولاً».
- حلقة حديثة مضمّنة مباشرة داخل الموقع.
- شبكة حلقات ومقاطع مختارة بروابط مباشرة إلى قناة الحدث اليوم.
- بيانات بث القناة على نايل سات: `11823 V / 27500`.
- روابط قناة YouTube وموقع الحدث اليوم.
- SEO وOpen Graph وTwitter Card وPerson structured data.
- Responsive بالكامل للموبايل والتابلت والكمبيوتر.
- تحسينات Accessibility: skip link، حالات focus، قائمة موبايل، ودعم reduced motion.
- بدون Frameworks أو Build Step — HTML / CSS / JavaScript فقط.

## مصادر المحتوى

المحتوى المرئي والـthumbnails مرتبطة بالمقاطع المنشورة عبر قناة **AlHadath Alyoum - الحدث اليوم** على YouTube، ومن بينها:

- «الوطن أولاً مع عباس سعد | جولة حول أهم الأحداث والقضايا» — 9 سبتمبر 2026.
- حلقة بتاريخ 5 أغسطس 2026.
- حلقات بتاريخ 22 يوليو و15 يوليو 2026.
- حلقة بتاريخ 28 فبراير 2026.

> لم تتم إضافة سيرة ذاتية أو حسابات شخصية أو بيانات اتصال غير موثقة. بيانات التواصل المعروضة تخص قناة الحدث اليوم ومذكورة بوضوح على هذا الأساس.

## التشغيل محليًا

يمكن فتح `index.html` مباشرة، أو تشغيل خادم محلي:

```bash
python -m http.server 8080
```

ثم افتح:

```text
http://localhost:8080
```

## النشر

المشروع Static ويمكن نشره على GitHub Pages أو Vercel أو Netlify.

### GitHub Pages

1. افتح **Settings → Pages**.
2. اختر **Deploy from a branch**.
3. اختر `main` ثم `/(root)`.
4. احفظ الإعدادات.
