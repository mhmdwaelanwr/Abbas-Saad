# محسن المليجي — برنامج الوطن أولاً

موقع عربي RTL تعريفي للإعلامي **محسن المليجي** وبرنامج **الوطن أولاً**.

## المميزات

- تصميم Responsive للموبايل والكمبيوتر.
- هوية بصرية بالأسود والأحمر مستوحاة من البرنامج.
- قسم تعريفي بالبرنامج ومقدم البرنامج.
- موعد البث والتردد.
- تضمين Playlist الحلقات مباشرة من YouTube.
- SEO و Open Graph أساسيان.
- بدون Frameworks أو Build Step — HTML / CSS / JavaScript فقط.

## التشغيل محليًا

يمكن فتح `index.html` مباشرة، أو تشغيل سيرفر محلي:

```bash
python -m http.server 8080
```

ثم افتح:

```text
http://localhost:8080
```

## النشر

المشروع Static ويمكن نشره على GitHub Pages أو Vercel أو Netlify.

### GitHub Pages

1. افتح **Settings → Pages**.
2. اختر **Deploy from a branch**.
3. اختر branch المطلوب ثم `/(root)`.
4. احفظ الإعدادات.
