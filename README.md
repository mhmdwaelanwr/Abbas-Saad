# عباس سعد — Media Profile

واجهة إعلامية عربية RTL للإعلامي **عباس سعد**، مقدم برنامج **«الوطن أولاً»** على قناة **الحدث اليوم**.

## الهدف

المشروع ليس صفحة تعريف تسويقية تقليدية، بل **Media Profile / Press Room** موجهة للصحفيين، المنتجين والقنوات، مع الاعتماد على بيانات وروابط يمكن إسنادها إلى مواد منشورة علنًا.

## الصفحات

- `index.html` — الملف الإعلامي الكامل، الأعمال المختارة، البرنامج وغرفة الصحافة.
- `press.html` — Media Kit مختصر قابل للطباعة أو الحفظ PDF.
- `404.html` — صفحة خطأ مخصصة.

## المميزات

- تصميم Editorial / Newsroom هادئ ومناسب للعرض المهني.
- أحدث مادة مختارة من «الوطن أولاً» بتاريخ 9 سبتمبر 2026.
- أرشيف أعمال بروابط مباشرة إلى قناة الحدث اليوم على YouTube.
- نبذة قصيرة قابلة للنسخ للاستخدام الصحفي.
- Media Kit منفصل للطباعة والمشاركة.
- بيانات بث القناة المنشورة: `11823 V / 27500`.
- SEO: canonical, Open Graph, Twitter Card, Schema.org, `robots.txt`, `sitemap.xml`.
- `site.webmanifest` ودعم تثبيت الموقع كتطبيق ويب بسيط.
- Responsive للموبايل والتابلت والكمبيوتر.
- Accessibility: skip link، focus states، reduced motion وقائمة موبايل قابلة للإغلاق بالكيبورد.
- بدون Frameworks أو Build Step — HTML / CSS / JavaScript فقط.

## سياسة المحتوى

لا تتم إضافة سيرة ذاتية موسعة، ألقاب، حسابات شخصية أو بيانات اتصال غير موثقة. الصور المصغرة والروابط تشير إلى مواد منشورة عبر قناة **AlHadath Alyoum - الحدث اليوم** على YouTube.

## التشغيل محليًا

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.
